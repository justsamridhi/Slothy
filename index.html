Chrome Extensions Manifest V3 Migration Guide

The gist

Manifest V3 enhances extension security, privacy, and performance by replacing background pages with service workers and disallowing remotely hosted code. Developers must migrate existing declarative network requests and update permission boundaries.

Key takeaways
  • Background scripts are replaced by event-driven service workers.
  • All extension code must now be packaged locally; no remote eval().
  • declarativeNetRequest replaces the blocking webRequest API for network filtering.

Quick Start

Install Slothy in under 2 minutes

No build step, no npm install, no bundlers. Pure vanilla Manifest V3.

1

Start Ollama

Ensure Ollama is running and pull your preferred Gemma model:

ollama pull gemma3:4b
2

Allow Extension Origin

Launch Ollama with permission to accept calls from Chrome extensions:

OLLAMA_ORIGINS="chrome-extension://*" ollama serve
3

Load Unpacked

Go to chrome://extensions, enable Developer Mode, click Load Unpacked, and select the slothy-extension folder.
